🚀 Sobre mim

Olá! Sou Luiz Miguel, profissional em formação na área de tecnologia, com conhecimentos em Análise e Desenvolvimento de Sistemas, Suporte Técnico e Gestão Empresarial.

Atualmente, atuo como Estagiário de Desenvolvimento Front-End no Instituto Saúde Aberta (I.S.A.), participando do desenvolvimento de interfaces para o aplicativo Gêmeos Saúde.

Tenho interesse em criar experiências digitais modernas, responsivas e acessíveis, unindo desenvolvimento, design e tecnologia.

Meu objetivo é evoluir continuamente como desenvolvedor e contribuir para a construção de soluções digitais que gerem valor para as pessoas.
